# Mohammed Zain — Personal Portfolio

A premium, responsive developer portfolio showcasing digital products, client websites, AI-powered applications, and full-stack engineering work.

## Highlights

- Interactive portfolio experience with responsive layouts and motion-led sections.
- Core expertise across frontend and backend development, AI automation, CMS/SaaS platforms, e-commerce integrations, and cloud deployment.
- Selected client website work, including Shefa Hospital, AA DESIGNO, and Nourish With Relma.
- Product work featuring AutoEditor and Titan Watches Voice Analysis.
- Downloadable resume and direct contact links.

## Tech Stack

- **Framework:** Next.js 14, React 18
- **Styling:** Tailwind CSS
- **Animation:** GSAP, Framer Motion, React Spring
- **3D & visuals:** Three.js, React Three Fiber, Drei
- **Scrolling:** Lenis
- **Deployment-ready:** Vercel

## Run Locally

Requirements: Node.js 18+ and npm.

```bash
git clone https://github.com/mdzxin93/personal-portfolio.git
cd personal-portfolio
npm install
npm run dev
```

Open http://localhost:3000.

## Production Build

```bash
npm run build
npm start
```

## Environment Variables

Create a local `.env.local` file only if your own integrations require environment variables. Never commit secrets or local environment files.
